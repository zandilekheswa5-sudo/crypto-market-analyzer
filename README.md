# Crypto Market Analyzer 🐍📊

A simple Python project that retrieves Bitcoin market data from the CoinGecko API, analyzes the data with Pandas, and visualizes price movements using an interactive candlestick chart.

## Features

- Fetches 30 days of Bitcoin OHLC data
- Converts API data into a Pandas DataFrame
- Calculates a 7-period moving average
- Displays an interactive Plotly candlestick chart
- Calculates:
  - Current Bitcoin price
  - 30-day high
  - 30-day low
  - 30-day percentage change

## Technologies

- Python
- Pandas
- Requests
- Plotly
- CoinGecko API
